小面（xiaomian）· 使用说明 / 操作指南  V3.1
========================================

完整文档（推荐）：见源码 docs\使用指南.md
或 GitHub：clothing-live-clipper/docs/使用指南.md

本文件是「绿包小白」精简版。


一、这是什么
------------
服装直播长视频 → 约 60 秒短成片。
本地听写 + 逻辑排片 + 可人工改后再重剪。


二、怎么启动（开箱）
--------------------
1. 解压 xiaomian-V3.zip 到短路径
     推荐：D:\xiaomian  或  C:\xiaomian
2. 进入解压文件夹，应能看到「启动小面.bat」
3. 双击：启动小面.bat
   - 首次可能提示安装 VC++，点「是」
   - 自动打开 http://127.0.0.1:8787/
4. 不用时双击：停止小面.bat

其它按钮：
  打开网页.bat        只开浏览器
  局域网启动.bat      同网段别人也能访问
  首次安装配置.bat    环境坏了再修
  修复GPU / 查看GPU状态


三、第一次必做：配 LLM
----------------------
网页右侧「LLM 用户配置」（可点展开）：
  1. 启用 LLM 逻辑排片
  2. Base URL（OpenAI 兼容，如硅基流动 https://api.siliconflow.cn/v1）
  3. API Key
  4. 模型（如 Qwen/Qwen2.5-7B-Instruct，可点自动匹配）
  5. 测试连通 → 保存并启用

Key 只存在本机：
  clothing-live-clipper\output\user_config\llm.json
不要把该文件发给别人。

不配 LLM 也能出片，但质量多为规则/本地兜底，一般较差。


四、日常剪片步骤
----------------
1. 左侧拖入/选择视频 →「开始服装切片」
2. 右侧看排队与进度（听写 → 排片 → 渲染）
3. 完成后中间可预览；右侧可「下载成片」
4. （可选）精修：
   - 左侧「口播时间轴」：改字/改时间，拖到中间加入
   - 中间「逻辑成片」：改顺序、删段、改时间
   - 选中几个字 →「删选中文字段」（中间删应保留前后两半）
   - 「裁掉从/到」按秒裁
   - 标题栏 ↶/↷ 或 Ctrl+Z / Ctrl+Y：撤销/恢复最近 2 步
     （只在点「保存并重剪」之前有效）
5. 点「保存并重剪」才会真正重出成片
6. 可勾选「自动学习」：把你的取舍记入本机偏好


五、成片规则（自动）
--------------------
要：版型、面料、显瘦、不透、细节、场景等
不要：尺码报码、价格发货、加一单、小黄车/链接、
      家人们/扣1、手速/开架/抱一下等直播过门

成片是「按时间裁原视频」，不是重新配音。
只改文字 → 声音不变；改时间/删句后需保存并重剪。


六、数据在哪（便携包）
----------------------
  clothing-live-clipper\output\web_jobs\   任务与成片
  clothing-live-clipper\output\user_config\  LLM 配置
  clothing-live-clipper\output\learning\     学习数据
  tools\logs\                                运行日志
  models\                                    听写模型

分发请用干净 zip，不要把用过的目录直接给别人。


七、常见问题
------------
Q：网页打不开？
A：再点启动；或先停止再启动。看 tools\logs\

Q：很慢？
A：无独显会走 CPU 听写；首次加载模型也慢。

Q：一直规则兜底？
A：LLM 测试是否成功；Key/地址/模型是否填对。

Q：第二条任务逻辑成片还是第一条的？
A：请用 V3.1，停止后重启，浏览器 Ctrl+F5。

Q：删中间字后面全没了？
A：V3.1 已修。Ctrl+F5 后重试；可用撤销回退。

Q：完全卸载？
A：停止服务，删除整个解压文件夹即可。


八、注意
--------
1. 杀软请信任本目录；首次 VC++ 可能要管理员确认。
2. 不要删 models、tools\python、tools\ffmpeg。
3. 休眠可能打断服务，唤醒后重新启动即可。
4. 本工具不能保证平台审核通过，发布前请再审片。

技术反馈：附 tools\logs 最新日志 + 任务 ID + 操作步骤。
