# 小面（xiaomian）使用指南 · V3.1

> **一句话**：服装带货直播长视频 → 约 **60 秒** 竖屏短片（去直播感，优先版型 / 面料 / 上身效果）。  
> 本地听写 + 逻辑排片 + 人工反剪 + 可选学习。支持离线绿色包开箱即用。

---

## 1. 适合谁 / 不适合谁

**适合**

- 服装主播、中控、短视频运营  
- 需要从直播回放里快速抽出「能卖货」的 1 分钟成片  

**不适合 / 当前不做**

- 多产品自动拆条  
- 声纹分离、自动烧字幕  
- 云端多人协作后台  

---

## 2. 两种使用方式

### 方式 A：离线绿包（推荐小白）

1. 获取 `xiaomian-V3.zip`（或桌面文件夹 `xiaomian-V3`）  
2. **解压到短路径**（重要）  
   - 推荐：`D:\xiaomian` / `C:\xiaomian`  
   - 避免：过长路径、纯中文盘符深层嵌套、需要管理员权限的系统目录  
3. 进入解压后的根目录，应能直接看到 **`启动小面.bat`**  
4. 双击 **`启动小面.bat`**  
   - 首次可能自动装 VC++（弹 UAC 点「是」）  
   - 依赖与模型已预置，**无需再 pip / 改路径**  
   - 浏览器打开：`http://127.0.0.1:8787/`  
5. 不用时双击 **`停止小面.bat`**

**其它根目录按钮**

| 文件 | 作用 |
|------|------|
| `启动小面.bat` | 启动本地服务并打开网页 |
| `停止小面.bat` | 停止服务 |
| `打开网页.bat` | 仅打开浏览器 |
| `局域网启动.bat` | 局域网访问（同网段其它电脑可访问本机） |
| `首次安装配置.bat` | 环境异常时重装/修复 |
| `修复GPU.bat` / `查看GPU状态.bat` | 显卡听写排障 |
| `先读我.txt` | 最短说明 |

### 方式 B：源码开发机

```bat
cd clothing-live-clipper
pip install -r requirements.txt
pip install faster-whisper
:: 有 NVIDIA 可再装 CUDA 相关包
start-web.bat
```

浏览器：`http://127.0.0.1:8787/`

## 3. 第一次打开网页必做：配置 LLM

右侧 **「LLM 用户配置」**（可折叠）：

1. 勾选 **启用 LLM 逻辑排片**（推荐开启）  
2. 填写：  
   - **Base URL**（OpenAI 兼容），例如 `https://api.siliconflow.cn/v1`  
   - **API Key**  
   - **Model**，例如 `Qwen/Qwen2.5-7B-Instruct`（可点「自动匹配」）  
3. 点 **测试连通** → 成功后再 **保存并启用**

说明：

- Key **只保存在本机**，一般在：  
  `安装目录\clothing-live-clipper\output\user_config\llm.json`  
- **不要**把该文件或整个用过的目录发给别人  
- 未配置 / 连通失败时：仍会出片，但走 **本地卖点 / 规则兜底**，质量通常弱于云端 LLM

## 4. 标准流程：从上传到下载

```
选择/拖入视频 → 开始服装切片 → 排队处理 → 自动听写与排片 → 预览成片
        ↓
   （可选）改口播 / 改逻辑成片 → 保存并重剪 → 下载成片
```

### 4.1 上传

1. 左侧 **导入视频**：点击区域或拖入文件  
2. 支持常见格式：`mp4 / mov / mkv / webm / avi / m4v / ts …`  
3. 点 **开始服装切片**  
4. 任务入队后，右侧 **当前任务** 可看状态、排队位次与等待/ETA  

默认：目标约 **60 秒**、默认会 **渲染成片**（绿包界面已隐藏多余开关）。

### 4.2 自动处理阶段（后台）

大致顺序：

1. **听写（ASR）** — 本地 faster-whisper（有 GPU 更快）  
2. **逻辑排片** — 优先云端 LLM；失败则本地卖点 / 规则兜底  
3. **渲染** — ffmpeg 按时间轴从原片裁切拼接  
4. 完成 → 预览区出现成片  

多人同时上传时：系统用 **排队 + 槽位**，听写等关键步骤可能串行，属正常。

### 4.3 下载

任务成功后，右侧按钮大致包括：

- **下载预览** / **下载成片** / **导出终稿**  
- **调试文件**（可折叠）：`plan.json`、`review.md`  

成片在任务目录内（见第 8 节）。

| 区域 | 内容 |
|------|------|
| **左上** | 导入视频、开始切片 |

## 6. 口播时间轴（左侧）

- 显示本任务听写出的句子（可改字、改开始/结束时间）  
- 操作：  
  - **拖到中间**逻辑成片的对应位置 → 插入（同句不重复）  
  - 点 **＋ / +加入成片**  
  - 多选勾选后批量加入  
- **青色 +「已加入」**：表示该句已在逻辑成片中  
- 折叠按钮可收起面板腾空间  

---

## 7. 逻辑成片（中间 · 精修核心）

成片结构是一条时间线（「逻辑 #1、#2…」），**按时间从原片裁切**，不是重新配音。

### 7.1 能改什么

| 操作 | 效果 |
|------|------|
| 改口播文字 | **只改标注文字**，不改变原片声音（除非再结合裁时间） |
| 改开始/结束秒 | **会改变**裁切区间 → 成片变化（保存并重剪后生效） |
| 删整段（×） | 去掉该段 |
| **删选中文字段** | 选中中间几个字删除，应保留 **前半 + 后半** 两段 |
| **裁掉从/到(s)** | 按秒精确裁掉区间 |
| 拖动手柄 / ↑↓ | 调整顺序 |
| 从左侧拖入 | 添加或替换（中间选区为插入） |

时间精度：**0.01 秒**。

### 7.2 撤销 / 恢复（V3.1）

标题栏 **保存并重剪** 左侧：

- **↶ 撤销** 或 **Ctrl+Z**  
- **↷ 恢复** 或 **Ctrl+Y**（或 Ctrl+Shift+Z）  

| 规则 | 说明 |
|------|------|
| 步数 | 最多 **2 步** |
| 何时可用 | **仅「保存并重剪」之前** |
| 何时清空 | 点保存并重剪、切换任务、重新加载服务器 plan |

### 7.3 保存并重剪

1. 改完后点 **保存并重剪**  
2. 可选勾选 **自动学习**（默认开）：把你的取舍写进本机偏好  
3. **清空学习**：抹掉全局学习数据  
4. 重剪完成后预览会刷新  

**未点保存并重剪 = 只改了界面，成片文件未更新。**

## 8. 数据与缓存位置（便携包）

以安装/解压根目录为 `安装目录`：

| 内容 | 路径 |
|------|------|
| 任务与成片 | `安装目录\clothing-live-clipper\output\web_jobs\{任务ID}\` |
| LLM 配置（含 Key） | `...\output\user_config\llm.json` |
| 反剪学习 | `...\output\learning\` |
| 服务日志 | `安装目录\tools\logs\` |
| 听写模型 | `安装目录\models\` |
| 本机 venv（若生成） | `安装目录\.venv\` |

**清理建议**

- 只清历史任务：删 `web_jobs` 下旧任务文件夹  
- 换电脑分发：用新打的 zip，不要复制自己用过的目录  
- **不要删** `models`、`tools\python`、`tools\ffmpeg`、程序 `src`

## 9. 成片内容规则（自动会做）

**尽量保留**

- 版型、显瘦、收腰、面料、不透、垂感、细节工艺、适用场景等  

**会剔除 / 压掉**

- 尺码报码、几斤穿、围度  
- 价格 / 发货 / 加一单 / 小黄车 / n 号链接  
- 家人们、扣 1、321、准备一下  
- **手速 / 开架 / 抱一下** 等催场过门（含混在卖点句里的也会拆掉）  

结构倾向：**钩子 → 上身效果块 → 面料块 → 细节 → 场景**，同主题尽量连在一起。

处理路径（右侧可看）：

1. **云端 LLM**（首选）  
2. **本地卖点兜底**  
3. **规则时长兜底**（前两者过短时）

## 10. 常见问题

**Q：双击启动没反应 / 找不到 Python？**  
A：请用绿包自带环境（`tools\python`）。若被杀软拦截，加入信任目录。看 `tools\logs\`。

**Q：网页打不开 8787？**  
A：再点启动；或先停止再启动。检查是否被占用、防火墙。日志：`uvicorn.err.log`。

**Q：听写很慢？**  
A：无 GPU 会走 CPU；首次加载模型慢。可用「查看 GPU 状态 / 修复 GPU」。  

**Q：一直规则兜底、质量一般？**  
A：右侧 LLM 测试是否成功；Key、Base URL、模型是否正确。

**Q：第二条做完了，逻辑成片还是第一条？**  
A：请用 **V3.1 及以后** 并 **Ctrl+F5**。若顶栏提示「前端偏旧」，说明还在旧缓存 JS。重启服务 + 强刷。

**Q：删选中中间字，后面全没了？**  
A：V3.1 已修。请确认 UI 为新版本；删完应变成前后两段，可用 **撤销** 回退试错。

**Q：只改字，成片声音怎么不变？**  
A：正常。裁的是 **原片时间**，不是 TTS。要变音画请改时间或删句后 **保存并重剪**。

**Q：旧任务会不会自动按新规则重剪？**  
A：不会。需对该任务 **保存并重剪** 或重新上传。

**Q：如何完全卸载？**  
A：停止服务 → 删除整个解压目录。

## 11. 推荐操作习惯

1. 短路径安装，杀软放行  
2. 先配好 LLM 再大批量  
3. 自动出一版 → 只精修问题句 → 再保存并重剪  
4. 改错用 **撤销**，确认后再提交重剪  
5. 成片上线前人工再看一遍（平台合规自负）
