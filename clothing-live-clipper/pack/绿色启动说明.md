# 绿色启动 / 打包方向说明

## 当前状态（已完成）

1. Web 上传后 **自动本地处理**，不需要 Agent 对话触发
2. HTML 已改成深色剪映风格三栏布局
3. 听写默认本地 faster-whisper
4. 可双击 `start-web.bat` 启动

## 最小绿色包结构（建议）

```
clothing-live-clipper-portable/
  start-web.bat
  README.md
  src/
  scripts/
  models/whisper-tiny/     # 把本地模型拷进来
  tools/ffmpeg/bin/        # ffmpeg.exe / ffprobe.exe
  python/                  # 可选：嵌入式 Python
  output/
```

## 启动脚本改造点

`start-web.bat` 增加：

```bat
set PATH=%~dp0tools\ffmpeg\bin;%PATH%
set CLIPPER_LOCAL_WHISPER_MODEL=%~dp0models\whisper-tiny
set PYTHONPATH=%~dp0src
python -m uvicorn clipper.web:app --host 127.0.0.1 --port 8787
```

## 下一步可选

1. 用 PyInstaller 把 `uvicorn + clipper.web` 打成 `ClipperWeb.exe`
2. 或用内嵌 Python 绿色目录，免安装
3. 首次启动自检：ffmpeg / 模型 / 磁盘空间

## 验收

- 无外网时可剪（模型与 ffmpeg 内置）
- 上传视频后自动出片
- 页面可预览下载
