【小面 xiaomian-V3 / V3.1 · 离线绿包】

1. 解压到短路径：D:\xiaomian 或 C:\xiaomian
2. 双击「启动小面.bat」
3. 网页右侧填写 LLM API → 测试 → 保存
4. 上传视频 → 开始服装切片
5. 可改「逻辑成片」后点「保存并重剪」
   - 撤销/恢复：↶↷ 或 Ctrl+Z / Ctrl+Y（保存前，最多 2 步）
6. 不用时「停止小面.bat」

详细步骤：使用说明-操作指南.txt
完整指南：源码 docs\使用指南.md

注意：
- 不要把用过的目录（含 Key / 任务）直接发给别人
- 日志：tools\logs\
- 出片约 60 秒；去直播感与尺码价格等
