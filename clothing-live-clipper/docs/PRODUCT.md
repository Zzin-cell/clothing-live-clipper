# 产品说明 · 小面 CapCut

## 1. 定位

面向 **服装带货直播** 的本地智能切片工具。

- 输入：直播回放视频  
- 输出：约 60 秒成片（默认 1.3x）  
- 目标：  
  1. **尽量看不出直播感**  
  2. **前 20 秒放最能吸引人的衣服特点**  
  3. 支持人工精修并反向重剪  

## 2. 目标用户

- 服装主播 / 中控  
- 短视频剪辑运营  
- 需要批量处理直播回放的商家

## 3. 产品原则

| 原则 | 落地 |
|------|------|
| 只要视频 | 不强制用户先写口播稿 |
| 先去噪 | 尺码/价格/控场/闲聊剔除 |
| 再抓重点 | 独特卖点与材质版型优先 |
| 人机协作 | 自动出一版 + 人工反剪 |
| 可学习 | 用户选择是否把本次修改写入全局偏好 |
| 本地优先 | ASR/渲染默认本机，可 GPU 加速 |

## 4. 成片标准

### 4.1 时长与节奏
- 目标成片：约 **55–65 秒**  
- 默认倍速：**1.4x**  
- 黄金段（前约 20 秒）：特点/卖点  

### 4.2 内容取舍
**要**
- 面料、版型、显瘦、遮肉、不透、垂感、弹力  
- 独家/专利/限定等独特点  
- 细节证据（蕾丝拼接、口袋等，偏后段）

**不要**
- 尺码建议（M/L、偏大偏小、胸围腰围）  
- 价格/优惠/挂车（券后、只要、小黄车、加购）  
- 直播控场（家人们、扣1、过一下、公屏、福袋）  
- 非服装闲聊  

### 4.3 结构
1. **黄金**：最强特点（独特优先）  
2. **信任**：证明与细节、后置换装搭配  
3. **收尾**：补充卖点复述（仍不讲价格）  

## 5. 用户路径

### 5.1 自动路径
上传视频 → 听写 → 过滤 → 排序 → 渲染 → 预览下载

### 5.2 精修路径
1. 在「口播时间轴」改词/改时码  
2. 拖入「成片结构」或点 +黄金/+信任/+收尾  
3. 在成片卡片中：  
   - 选中文字 → **删选中文字段**（裁小时间段）  
   - 或「裁掉从/到」精确裁秒  
   - 或删整段 / 替换 / 重排 / 均分时长  
4. 可选勾选 **学习这次重剪**  
5. **保存并重剪成片**

## 6. 关键说明（务必知晓）

- 成片是 **按时间裁原视频**，不是 TTS 重配音。  
- **只改文字**不会改变原片声音。  
- **删小句/改时间/删整段** 才会改变成片音画。  

## 7. 成功指标（MVP）

- 成片可直接用于试投/挂车素材  
- 前 20 秒无尺码价格控场  
- 人工精修路径可在 2–5 分钟内完成  
- 学习开关可开可关，清空可重置  

## 8. 非目标（当前不做）

- 全自动多产品拆分  
- 声纹分离主播  
- 自动字幕烧录（可后加）  
- 云端多人协作后台
