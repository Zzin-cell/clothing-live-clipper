【0】如何打干净包（开发机）
--------------------------------------------------------------------------------
  [ ] 在开发仓库执行（不要从「已跑过任务」的桌面目录手工 zip）：

      cd /d C:\Users\MR\AppData\grok\clothing-live-clipper
      set PYTHONPATH=src
      python scripts\build_portable_package.py

  [ ] 产物默认位置：
      文件夹：%USERPROFILE%\Desktop\小面CapCut-便携版\
      压缩包：%USERPROFILE%\Desktop\小面CapCut-便携版.zip

  [ ] 打包完成后立刻验收本清单，通过后再改名分发
  [ ] 禁止：把用过的便携目录整夹 zip 给别人/拷进虚拟机


【1】解压与路径（最容易踩的坑）
--------------------------------------------------------------------------------
  [ ] zip 内仅一层主目录（名称建议固定：小面CapCut-便携版）
  [ ] 解压后双击「启动小面.bat」的目录内，能直接看到 bat/先读我
      —— 不要变成：xxx\小面CapCut-便携版 (3)\小面CapCut-便携版\…
  [ ] 验收与生产部署路径优先短英文路径，例如：
        D:\xiaomian\
        C:\xiaomian\
      避免：Desktop\…便携版 (3)\…、超长中文+空格+括号
  [ ] 路径总长度建议：包根路径 < 60 字符；不要嵌套多层中文

  对照 build 脚本 write_root_bats + 拷贝文案：

  [ ] models\                         （可空或已有模型）
  [ ] tools\                          （ffmpeg 等；logs 可空）
  [ ] output\                         （空骨架：web_jobs / user_config）

  可选（有则更好，无也不否决「标准包」）：
  [ ] 局域网启动.bat / 修复GPU.bat / 查看GPU状态.bat

  [ ] 内容调用 pack\portable\ensure_ready.ps1（首次自动安装）

  [ ] 失败时有 pause / 提示看 tools\logs\
  [ ] 打开网页指向 http://127.0.0.1:8787/

【5】应用代码（clothing-live-clipper）—— 必须有

  [ ] src\clipper\web.py

【6】模型 models\
--------------------------------------------------------------------------------
  标准 build 默认会尝试拷贝（若开发机有）：
  [ ] models\whisper-small\model.bin   （推荐至少有一个）
  和/或
  [ ] models\whisper-tiny\model.bin

  说明：
  · whisper-medium 体积大，是否预置看「超全量」产品策略
  · 若 models 全空：首跑必须联网下模型 —— 须在先读我/说明里写清
  验收：
  [ ] 至少存在 1 个 model.bin 且 > 1MB    或
  [ ] 明确标注「首次联网下载模型」且安装日志能完成下载


【7】工具 tools\
--------------------------------------------------------------------------------
  [ ] tools\ffmpeg\bin\ffmpeg.exe      （打包机若有 LOCALAPPDATA\ffmpeg 会拷入）
  [ ] tools\logs\ 为空或仅占位（无上机泄露的大量业务日志）
  可选超全量：
  [ ] tools\python\python.exe          （空白机免装系统 Python）


【8】体积红线（相对失败案）
--------------------------------------------------------------------------------
  失败案参考：整包夹带 web_jobs ~7GB + 脏路径，zip ~2GB「假便携」。

  干净包建议（按是否预置模型浮动）：

  | 形态           | 解压目录大致     | zip 大致        |
  |----------------|------------------|-----------------|
  | 仅代码+脚本    | 远小于 500MB     | 通常 < 100MB    |
  | +ffmpeg+small  | 约 0.6～1.2GB    | 视压缩率        |
  | +medium 全量   | 约 2～3GB 级     | 仍应 << 脏包    |

  硬性否决：
  [ ] clothing-live-clipper\output 下无成片/无 uploads 视频堆
  [ ] 不存在数十个 web_jobs\2026… 任务目录
  [ ] 未把本机 .venv 打进交付 zip


【9】禁止出现的「本机污染」
--------------------------------------------------------------------------------
  [ ] 配置文件中无写死 C:\Users\某用户\Desktop\… 绝对路径
  [ ] 无别人的 API Key 留在 output\user_config\llm.json
  [ ] 无学习库脏数据必须分发（output\learning 宜空）
  [ ] 元数据/日志不暗示「上一位用户」任务列表

【11】GPU 机附加（有 NVIDIA 时）
--------------------------------------------------------------------------------
  [ ] 安装日志出现 NVIDIA GPU 探测 或 device_hint cuda

  [ ] 无长期「environment variable is longer than 32767」导致无法 CUDA
      （若出现：缩短包路径、清理系统 PATH 后再验）
