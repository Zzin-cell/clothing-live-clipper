# 绿色启动 / 小白便携包说明

## 当前已完成

1. **一键启动**：双击 `启动小面.bat`  
   - 首次自动安装/修复环境（venv、依赖、ffmpeg、模型、桌面快捷方式）  
   - 后台启动 uvicorn（**无需一直挂着 PowerShell 窗口**）  
   - 自动打开浏览器 `http://127.0.0.1:8787/`
2. **自动排查修复**  
   - 坏 venv 重建  
   - pip 清华/阿里/官方镜像重试  
   - ffmpeg / 模型多源下载  
   - GPU 失败自动回退 CPU 听写  
   - 8787 端口占用清理
3. **本地听写**：faster-whisper（优先 `models/whisper-medium`，否则 small/tiny）
4. **LLM**：网页右侧用户自配 API（不读共享 env 密钥）
5. **空白机实测已通过**（见 `scripts/_blank_install_test.py`）

## 给用户的包怎么用

桌面生成：

- 文件夹：`小面CapCut-便携版\`
- 压缩包：`小面CapCut-便携版.zip`

小白步骤：

1. 解压  
2. 双击 **`启动小面.bat`**（首次会自动安装，需联网）  
3. 浏览器右侧填 Base URL / Model / API Key → 测试 → 保存  
4. 上传视频切片  
5. 不用时双击 **`停止小面.bat`**

文档：

- `先读我.txt`
- `使用说明-操作指南.txt`
- `注意事项.txt`

## 开发者：如何重新打包装包

在仓库 `clothing-live-clipper` 下：

```bat
set PYTHONPATH=src
python scripts\build_portable_package.py
```

输出到当前用户桌面。

健康检查：

```bat
python scripts\_check_portable_health.py
```

空白机安装实测：

```bat
python scripts\_blank_install_test.py
```

## 包内关键脚本（`pack/portable/`）

| 文件 | 作用 |
|------|------|
| `ensure_ready.ps1` | 不健康则自动安装 |
| `install_all.ps1` | 完整安装 + 镜像重试 + 修复 |
| `start_service.ps1` | 隐藏窗口启动服务 + 自愈重启 |
| `stop_service.ps1` | 停止 8787 |

## 目录结构（交付包）

```
小面CapCut-便携版/
  启动小面.bat
  停止小面.bat
  打开网页.bat
  首次安装配置.bat   # 可选手动重装
  先读我.txt
  使用说明-操作指南.txt
  注意事项.txt
  clothing-live-clipper/   # 程序
  pack/portable/           # 安装启动脚本
  models/                  # whisper（可预置或首次下载）
  tools/ffmpeg/bin/        # 便携 ffmpeg
  tools/logs/              # 安装/启动日志
  .venv/                   # 首次安装后生成
  output/                  # 任务输出与用户 LLM 配置
```

## 环境前提

- Windows 10/11  
- 已安装 **Python 3.10+**（含微软 Store / `py` 启动器亦可）  
- 首次安装需联网  
- 建议 NVIDIA 显卡（无显卡自动走 CPU）
