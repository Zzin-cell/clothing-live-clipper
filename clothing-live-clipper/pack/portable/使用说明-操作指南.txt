小面 CapCut · 小白操作指南
================================

本软件用于：服装直播长视频 → 约 60 秒短成片（去直播感，优先版型/面料/上身效果）。


一、你需要准备
--------------
1. Windows 10 / 11 电脑
2. 已安装 Python 3.11 或 3.12
   - 官网：https://www.python.org/downloads/windows/
   - 安装时务必勾选：Add python.exe to PATH
3. 可上网（首次安装要下载 ffmpeg 与语音模型）
4. （推荐）NVIDIA 显卡：听写更快；没有也能用，会更慢
5. 一个 OpenAI 兼容的大模型 API（如 SiliconFlow / 中转站）
   - 自行注册并复制 API Key


二、解压后第一次使用（只需做一次）
--------------------------------
1. 解压整个文件夹到英文路径最好，例如：
     D:\XiaomianCapCut\
   不要只解压某一个 bat，整个目录都要在。
2. 双击：  首次安装配置.bat
   - 自动创建 Python 虚拟环境
   - 自动安装依赖
   - 自动下载便携 ffmpeg
   - 自动下载 whisper-small 语音模型
   - 自动在桌面创建快捷方式「小面CapCut」
3. 看到「INSTALL_OK / 安装成功」即可


三、每天怎么用
--------------
1. 双击桌面「小面CapCut」，或文件夹里的「启动小面.bat」
2. 会自动：
   - 在后台启动服务（可关掉弹出的黑窗口）
   - 打开浏览器 http://127.0.0.1:8787/
3. 在网页右侧「LLM 用户配置」填写：
   - Base URL：例如 https://api.siliconflow.cn/v1
   - Model：推荐 Qwen/Qwen2.5-7B-Instruct（轻量稳定）
   - API Key：你自己的 Key
   → 点「测试连通」→「保存并启用」
4. 上传服装直播视频 → 开始切片
5. 处理完成后：下载成片（文件名 ≈ 原名+final.mp4）
6. 不用时：双击「停止小面.bat」关闭服务


四、成片规则（自动）
--------------------
- 目标约 60 秒，竖屏 2K 级 MP4，H.264 30fps
- 开头优先：服装特点（版型/面料/上身效果）
- 可保留：不走光、不显肚子、拜拜肉、胃包 等上身效果
- 会删除：尺码报码（M/L、几斤穿）、价格发货、加一单、直播控场、夸大引流


五、注意事项
------------
1. 启动后**不需要**一直挂着 PowerShell / 黑窗口；服务在后台运行。
2. 首次听写会加载模型，稍慢属正常。
3. 必须先填对 API，否则只能走规则兜底（质量可能差一些）。
4. 旧任务不会自动重剪；改设置后请上传新任务或「保存并重剪」。
5. 模型默认 small；若你把 medium 模型放进 models\whisper-medium\ 会自动优先用。
6. 杀毒软件可能拦截首次下载；请允许联网与本目录运行。
7. 不要删除 tools、models、.venv 目录。
8. API Key 只存在本机 output\user_config\llm.json，请勿把该文件发给别人。
9. 电脑休眠可能让后台服务中断，唤醒后重新点「启动小面」即可。
10. 本工具不能 100% 保证平台审核通过，发布前请再看一遍成片与文案。


六、常见问题
------------
Q：双击没反应？
A：右键用「以管理员身份运行」安装配置；确认已装 Python 并勾选 PATH。

Q：网页打不开？
A：再点一次「启动小面.bat」；或运行「停止小面.bat」后再启动。
   日志：tools\logs\uvicorn.err.log

Q：一直规则兜底？
A：检查右侧 API 是否测试成功；推荐 Qwen2.5-7B-Instruct。

Q：如何完全卸载？
A：运行「停止小面.bat」，删除整个解压文件夹，删除桌面快捷方式即可。
